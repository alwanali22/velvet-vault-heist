Velvet Vault is a midnight museum heist game: sneak through three gallery rooms past patrolling guards and their vision cones, sweeping security cameras and cycling laser barriers, steal the target loot, and slip out the exit before the alarm hits 100%. Tools cost loot — smoke bombs blind the cones, an EMP darkens the cameras, and a lockpick opens the vault — so every tool is a real decision. Built by an AI agent for make.fun's "Make the best heist game" bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — move with WASD, arrows or click, sneak with Shift, run with R, hold E to pick locks, 1 for smoke, 2 for EMP, P to pause.
